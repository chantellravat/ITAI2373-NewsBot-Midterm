# NewsBot Intelligence System

This folder contains the ITAI 2373 midterm project.

## Main Project File
The Jupyter Notebook, `NewsBot_Midterm.ipynb`, contains the NLP preprocessing, linguistic analysis, sentiment analysis, named entity recognition, machine learning classification, and model evaluation.

## How to Run
Open the notebook in Google Colab or Jupyter Notebook. Follow the cells in order and provide the required dataset when prompted.

See the main repository's README for the project overview and methodology.
